# santa-tracker-assets

Public images for the Santa Tracker Attio app. Attio's `Image` component needs a public HTTPS URL,
so these are served through jsDelivr from tagged versions, e.g.

https://cdn.jsdelivr.net/gh/shyaamdylan/santa-tracker-assets@v1/map-hero.png

Only made-up demo companies appear in these images. Never add real customer data here.

Regenerate in the app repo with `npm run render:hero`, copy the PNG here, commit, and tag a new
version (v2, v3, …) so the CDN serves the fresh file.
